## 初态与原轮廓保护

Pipedream构造器会执行初始化微步，因此构造后明确恢复六类H/h/Q，再重算几何/储水，清零计数并设置起时；逐元素核验初态恢复。n/C应用前后六类状态不变，n只落在POOL16明渠，倒虹吸和上游短段保持不变。

两个假设都从不使用H16评分实测的水面猜测开始。若水平初猜高于开敞原轮廓，仅在t0选择原顶下0.05m的合法初始水面，同时处理相邻非边界节点；B闭管出口真实假设边界保留，不截低尾水。正式推进从不夹内部水位，不改g1或段类型。

开敞断面范围检查和闭管压力水头分开：B两处闭管内部节点不按开敞管顶限制。人工切口无附加储水/端损；原闸邻接端部和B倒虹吸出口端部关系保留。逐孔宽度、基础C及实际开度序列保持，归一化高度不是新确认的机械门高。

## B：合法初态后的求解尝试失败

第一窗的窗均值低初值基准返回converged=False、status=NOT_CONVERGED_CONTINUING、stop_reason=verification_numerical_failure。原adaptive按15→7.5→3.75→1.875s缩步/回退，之后15s验证也失败；累计接受0步、拒绝5步，验证0/240步。

最终保存状态仍为合法起点，开敞原顶最小余量0.05m、超出点数0；被拒绝尝试最大超高0.937697m。不能写成“接受了越界稳态”。第一窗没有认证，故未运行B高初值预热、第二窗、T04或任何拟合。

只读定位表明失败点是开敞q16s26（local junction73），桩号327407m、底116.36m、轮廓顶124.780m；不是闭管节点。B使用的H17序列范围为125.939862—126.577830m，第一窗规定均值126.010007m。该组合明确暴露输入轮廓适用范围与此测点语义假设之间的矛盾，但轮廓端点不是已核实堤顶，不据此报告现场漫顶。

## 调用接口

```python
from 测点假设局部模型 import build, forcing, mean_forcing, sample, steady, advance, change
local = build('A', t0=237600, n_factor=1.0, c_factor=1.0)
hold = mean_forcing(local, 216000, 237600)
result = steady(local, kw=hold)
assert result['converged'] and result['accepted_final_exceeded_points'] == 0
change(local, 'n', 1.05)  # 绝对倍率，以源基准n为准；不改H/Q
values = sample(local)  # JZZ16_forebay_m / JZZ16_afterbay_m 为内部目标
```

`change`也支持n_factor/c_factor关键字和n16/C16别名，原B02倍率界不变。`advance(local,t0,t1)`仍返回(rows,retries)。`local["base_n"]`、`base_C`保存原参数，`factors`保存当前倍率；audit的gate_rows是基础转换记录，实际应用C以model._Co为准。

`runtime_audit`留存所有检查及拒绝尝试；steady返回另列最终接受状态范围，不以历史拒绝次数代替最终稳态认证。输出sample中的boundary_tailwater_m不能计分。
