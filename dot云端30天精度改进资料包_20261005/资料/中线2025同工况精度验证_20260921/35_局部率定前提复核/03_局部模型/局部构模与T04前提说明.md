# 局部构模与T04前提说明

## 结论

**十二里河、兰河短闸段可以在现有映射条件下开展固定糙率的条件性C辨识，不需要全线同时稳态。** 两个短段已按实际测流及水位测点桩号截取，完成双初值稳态、提前24小时实际时变推进，以及末时/窗均值T04对照。它们通过预先规定的模型内判据，不代表测点物理位置、仪器身份和源几何都已独立确证。

兰河至颍河前长段已完成构模预检，**未启动长段水力推进或率定**。颍河327100m绝对桩号与“闸前0.5m”位置描述存在物理冲突，不能自动移点或把当前插值候选直接当现场尾水真值。

本模块不做C拟合或保留期评分；这些由相邻04目录的主流程负责。原转换器、求解器、C07及冻结B01/B02均未修改。

## 几何与实际运行数组核验

1. 从原C07相关渠道展开原`num_interp`计算断面，保留切口范围内原计算点，仅在实际切口新增由现有safe算法插值得到的断面。新断面不再二次加密，未移动原闸节点。JZZ6/JZZ16短段各4条内部连接；长段71条。
2. 闸孔保留原模型的两孔、底高程、宽度、系数相对关系和逐孔实际开度。JZZ6每孔宽13m，JZZ16每孔宽12m；`y_max=13/12m`沿用既有控制归一化尺度，**不是新核定的机械门高或行程**。逐时`u_o×y_max`与原治理后开度核对，无截断；具体数值在逐孔开度与原参数保持核验.json。
3. 各保留普通渠段n仍为原0.015；基础C仍来自既有Pipedream闸流系数文件。倍率界取冻结B02，不放宽。
4. 人工数学切口不能增加一座虚假蓄水池或局部构筑物损失。经实际运行数组检查，两个切口`m._A_sj`均为0、对应端头损失系数为1e-18；原闸邻接端头仍是0.20151121000000005。不是只检查配置表。
5. Pipedream构造器有初始化微步。本入口随后明确恢复六类初始H/h/Q，重算几何、储水，t与迭代计数归零/指定起时，逐元素核验。不存在把构造器产生的异常流量当初态的情况。
6. 模型内切口的绝对桩号有明确记录；节点x/y保留占位坐标，仅用于满足原数据结构，不用于认定新切口GPS位置。水力长度及观测位置均由断面桩号确定。

## 调用接口

```python
from 局部闸段 import build, forcing, mean_forcing, steady, sample, advance

local = build('JZZ6_short', t0=174600, c_factor=1.0)
kw = mean_forcing(local, 153000, 174600)
result = steady(local, kw=kw)
assert result['converged']
values = sample(local)

# 历史回放需另起同一case，先准备起点；尾水不评分。
replay = build('JZZ6_short', t0=0, c_factor=1.0)
assert steady(replay, t=0)['converged']
rows, retries = advance(replay, 0, 86400)
audit = replay['runtime_audit']
```

`build`返回engine/model/source/converted/forcing/operators/audit/raw_heights/runtime_audit。`advance`返回`(rows,retries)`，不改变参数；`mean_forcing`返回时间加权边界、逐孔开度、逐处分水数组。

`runtime_audit`每一步累计检查次数、最大超原轮廓量、超出次数及点次。超过原轮廓抛异常并保留最后异常时间/断面/超高，不接受截高状态作为率定结果。记录包含预热尝试；回退前的异常尝试仍留痕，不应混同正式过程接受步数。低C试算可能超原轮廓，应记为不可行，在原参数界内寻找可行括区，不扩大参数界或断面高度。
