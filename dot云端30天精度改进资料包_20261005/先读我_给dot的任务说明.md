## 如何比较新候选

在独立目录保存候选源码和结果。候选输出沿用原字段，包括水位、流量、实际测点位置、水量收支和运行配置。完整成功后运行：

```bash
python 云端评分.py --reference 云端新结果/reference --candidate 候选结果目录 --output 候选评分目录
```

评分入口复用原始41轮程序，计算全30天和后15天的分组、逐点误差及原条件性精度门槛。输出中的 `endpoint` 列只是复用程序对候选的名称，不表示候选已经安装端面修复。

评分入口不代替数值和物理检查。每个新候选仍须核查逐步水量收支、非定水位节点连续方程残差、几何轮廓适用范围、失败回退和六态有限性。原运行器会生成这些记录。资料包未携带旧的逐成功子步残差分块，历史完整过程CSV、结果和核验结论仍在；需要重新核查某个历史分块时，必须按对应原入口重建，不能声称已复查未携带的分块。

## 必须保持的比较口径

- 首轮复现保持原糙率、闸流系数、初始状态、开度及边界过程；不通过同化或直接校正内部水位压低误差。
- 优先查明断面、桩号、闸底、结构连接、局部损失、边界及测点位置问题。每项修改有来源或独立物理反例，单独对照后再考虑组合。
- 本月已被反复查看。后15天及旧9点沿用固定口径作复核，不宣称新的盲测或未来预测。其他时段实测未包含在本任务验证范围。
- 主要水位组是118闸节点、43安装位置和旧9点；补充保留原88点、旧34点。水位统计同时给MAE、RMSE、偏差、最大误差和逐点变化。
- 全月和后15天主要水位组MAE/RMSE均不变差，任一水位表示的逐点MAE退化不超过1厘米；每个时段至少一主组MAE改善达到 `max(2毫米, 参考MAE的5%)`。这是既定条件性门槛，不等于全面工程验收。
- 44处测流保留统计，JZZ17、JZZ59存在端部最近连接中心近似，须单列；兰河半小时平均流量与末步瞬时流量分开。流量、水量平衡和模型蓄变不得被水位平均指标掩盖。
- 不按误差好坏剔除测点、改时间轴、改实测或改变有效样本。源资料错误与模型精度是两类结论，某项正确修复没有精度收益也须如实保留。
- 如提出参数率定，把参数范围、分组依据、调整时段及验证口径作为独立候选明确记录；不要把同化分析值当成自然演进的模型精度。当前未授权把候选替换生产基线或部署。
